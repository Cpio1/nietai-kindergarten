# Сайт «Ниетай бөбекжай-бақшасы»

Next.js, TypeScript, Tailwind CSS и Framer Motion. Казахская версия открывается по адресу `/`, русская по адресу `/ru`.

## Запуск

```bash
npm install
npm run dev        # разработка: http://localhost:3000
npm run build      # продакшен-сборка
npm run typecheck  # проверка TypeScript
npm run lint       # проверка ESLint
```

## Структура

| Путь | Что находится |
| --- | --- |
| `src/website/` | Версия для компьютера, экран от 1024px |
| `src/mobile-website/` | Отдельная версия для телефонов и планшетов, экран меньше 1024px |
| `src/shared/` | Общие компоненты, иллюстрации, поиск медиафайлов |
| `src/content/dictionary.ts` | Все тексты на казахском и русском языках |
| `src/content/site.ts` | Телефон, координаты и данные 2ГИС |
| `src/content/groups.ts` | Семь групп: сюда добавляются названия и возраст |
| `public/images/` | Фотографии |

## Как обновлять сайт

Медиафайлы подключаются во время сборки: после добавления файлов нужен новый деплой.

### Фотографии

Положите файлы в `public/images/`. Форматы: JPG, PNG, WebP, AVIF.

| Имя файла | Где появится |
| --- | --- |
| `main-page.jpg` | Первый экран. Пока файла нет, на этом месте показан логотип |
| `main-page2.jpg` или `main-page2.mp4` / `.webm` | Раздел «Біз туралы» (фото или видео) |
| `image1.jpg`, `image2.jpg`, … и любые другие имена | Галерея, по порядку номеров |
| `club-dance.jpg`, `club-taekwondo.jpg` | Фото кружков вместо иллюстраций: в галерею не попадают |
| `logo.png`, `logo-transparent.png`, `logo-mark.png` | Логотип и знак-солнышко: в галерею не попадают |

Если в галерее нет ни одной фотографии, раздел и пункт меню скрыты. Повреждённые файлы пропускаются. Формат HEIC с iPhone не поддерживается: сначала сконвертируйте такие фото в JPG.

### Ссылка на документы

Задайте переменную окружения `NEXT_PUBLIC_DOCUMENTS_URL` с настоящей ссылкой на Google Drive. Принимаются только адреса `https://drive.google.com/...` и `https://docs.google.com/...`. Пока ссылки нет, кнопка неактивна.

### Группы

Когда появятся названия и возраст, добавьте их в `src/content/groups.ts`:

```ts
{ critter: "bear", color: "#F8C65C", name: { kk: "…", ru: "…" }, ages: { kk: "…", ru: "…" } },
```

Зверята на иллюстрациях только украшение и не являются названиями групп.

## Развёртывание на Vercel

1. Загрузите проект в репозиторий GitHub и импортируйте его в Vercel. Настройки сборки определятся автоматически.
2. В **Settings → Environment Variables** добавьте значения из `.env.example`.
3. После изменения переменных запустите новый деплой: они подставляются во время сборки.

## Подключение домена edu.kz

1. В Vercel откройте **Settings → Domains** и добавьте домен.
2. Внесите DNS-записи, которые покажет Vercel, в панели регистратора домена.
3. Укажите `NEXT_PUBLIC_SITE_URL=https://<ваш-домен>` и запустите новый деплой. От этого зависят canonical, `sitemap.xml`, `robots.txt` и разметка для поисковиков.
